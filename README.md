# Riera Studio – öffentlicher Prototyp

Statische Demo-Anwendung für Video-Workflow, plattformbezogene Bearbeitung und Affiliate-Kommentarregeln. Die Demo benötigt keine Installation und speichert Nutzereingaben lokal im jeweiligen Browser.

## Grenzen

- Keine Cloud-, Meta- oder TikTok-Verbindungen
- Keine echten Veröffentlichungen oder Kommentarantworten
- Keine gemeinsame Datenbank oder Benutzeranmeldung
- Der Videoexport läuft lokal und ist browserabhängig
